
# Trabajo Práctico con Pandas y SQLite

En este proyecto se analiza el archivo `Salaries.sqlite` utilizando `pandas` y `sqlite3`. El objetivo es practicar la manipulación de `DataFrames`, filtrado, limpieza y agregación de datos.

## Herramientas utilizadas

- Python 3
- pandas
- sqlite3
- Jupyter Notebook

## Requisitos

Para ejecutar este proyecto se recomienda usar un **entorno virtual** y tener Python 3.8 o superior.

### Instalación

# 1. Clonar el repositorio

```bash
git clone https://github.com/AlanRik20/pandas_df_tlp3_alan_riquelme.git
cd pandas_df_tlp3_alan_riquelme
```

# 2. Crear entorno virtual

ingresar en una consola de PowerShell y escribir:

```bash
python -m venv env
```

# 3. Activar entorno virtual

```bash
.\env\Scripts\activate
```

# 4. Instalar dependencias

```bash
pip install -r requirements.txt
```

## Ejecución

1. Abrir el notebook `actividad_df.ipynb`.
2. Ejecutar cada celda siguiendo el orden para ver los resultados del análisis.
